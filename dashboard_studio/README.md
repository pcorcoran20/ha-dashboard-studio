# Dashboard Studio add-on

Design beautiful dashboards with drag and drop, right inside Home Assistant, then install them in one click.

- Uses your real entities, names and areas
- 21 blocks, 14 themes, moving backgrounds and a full customize panel
- A touchscreen-style Control hub with rooms, scenes, an alarm keypad and a Good night button
- One-click install: dashboard, theme, hub card, scripts, scenes and automations

See the **Documentation** tab for how it works.
